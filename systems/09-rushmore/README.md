**The cast.** Several characters take turns in one scene, round-robin, and each one sees everything said so far before it speaks.

- **The scene** is `system.md`: the situation every character is given.
- **The characters** are the files in `cast/`, one each: who they are, what they like best, how they argue, and a `voice:` line. Each is a separate model call with only its own file and the scene.
- **The turn count:** `speeches: 20` is twenty speeches in all, five each in turn order (Washington, Jefferson, Roosevelt, Lincoln, then around again). The dashboard counts them.
- **The caps:** twenty speeches, the cost ceiling, and Stop.

Nothing else is in this one: no director, no producers, no private asides. To try: give them a new subject, add a fifth character, or change `speeches:`. For something much bigger, see the Divine Villa, and the prompt to make your own at the bottom of this page. Copy the folder to a new name first, so this one stays as it is.
