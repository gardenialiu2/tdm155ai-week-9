# TDM 155AI week 9: the app

A Next app that renders the Markdown in `content/` (its README is the home page; `content/a/b.md` is `/a/b`) (`lib/content.mjs`). `/docs` (`app/docs/`) shows `content/docs/` as a docs site with a sidebar (`app/components/DocsSidebar.jsx`). The header nav is Docs, Theater, Runs, Research, Glossary, Podcast prep, Remix (`app/components/Chrome.jsx`). `/theater` (`app/theater/`, engine in `lib/theater/`) runs the systems in `../systems/`; `/podcast` (`app/podcast/`, engine in `lib/podcast/`) is podcast prep; `/remix` (`app/remix/`) is a self-contained copy of podcast prep for students to change; `/ai-research` renders `content/ai-research/`. `/ensemble` (`app/ensemble/`) is the ensemble: four roles (Conductor, Archivist, Researcher, Briefer) whose prompts and messages are in `app/ensemble/prompts.mjs`, imported by the page and the route and shown on the page; `api/run` makes one model call per role through OpenRouter, `api/sample` serves `../sample-context-repo/`, and `trace.mjs` writes the run as Markdown. `/ensemble/remix` (`app/ensemble/remix/`) is its self-contained copy. Keys come from the repo's root `.env` through `lib/keys.mjs`. Every other file and folder renders through the catch-all `app/[...slug]/`; images beside a doc are served by `app/context-media/`, and a light `/print` renders any page. See the repo `README.md`.
